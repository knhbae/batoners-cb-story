# 우리 모임의 다음 장

바토너스 CB 투자와 소득공제, 사업 자문회의 운영 구상을 설명하는 8장 만화입니다.

- [만화 보기](https://knhbae.github.io/batoners-cb-story/)
- [전체 설명과 법령·절차 근거](https://knhbae.github.io/batoners-cb-story/guide.html)
- [지인·가족용 별도 안내](https://knhbae.github.io/batoners-cb-story/friends/): 모임 구성원의 지인·가족 대상, 300만원부터 100만원 단위
- [두 안내본의 변경 내용 비교](design/FRIENDS-CHANGES.md)

## 읽는 방법

- 다음·이전 버튼, 목차, 진행 막대로 페이지를 이동합니다.
- 키보드 좌우 화살표와 Home/End를 지원합니다.
- 휴대폰에서는 좌우로 쓸어 넘깁니다. 긴 장은 아래로 스크롤해 읽습니다.
- 4·5장에서 과세표준을 선택해 세액 감소와 3년 단순 연환산 값을 비교합니다.
- 전체 설명은 별도 페이지로도 제공하며 인쇄할 수 있습니다.

## 내용 기준

2026년 11월 23일 참여 의사 확인용 초안입니다. 1,000만원 투자 예시의 세액 감소액은 165·264·385만원, 연환산 비교율은 5.50·8.80·12.83%입니다. 적용 요건과 계산 가정은 전체 설명에서 확인할 수 있습니다. 만화의 수치가 실제 이자·보장수익률·개인별 확정 절세액을 뜻하지는 않습니다.

신청·결제·개인정보 수집·분석 추적 기능은 없습니다. 공개 설명문과 삽화, 사이트 소스만 포함하며 회사의 원본 정관·계약서·내부 Notion 자료는 포함하지 않습니다. 검색 제외 태그를 사용하지만 GitHub 저장소와 Pages는 공개입니다.

## 수정·실행

- `app.js`: 8장 대사, 설명, 세금 예시와 이동 기능
- `guide.html`: 전체 설명, 표, 일정, 근거 링크
- `styles.css`: 책 레이아웃과 화면 크기별 배치
- `assets/`: 삽화, 글꼴, 글꼴 라이선스

로컬 미리보기:

```text
npm install
npm start
```

브라우저에서 `http://127.0.0.1:4173`을 엽니다. 사이트는 빌드가 필요 없는 정적 HTML/CSS/JavaScript이며, GitHub Pages의 main 브랜치 루트에서 배포합니다.
