# 설명회 초안 검증 · 2026-11-28

## 범위

`briefing/`에 15장 발표자료를 추가했다. 기존 루트·friends 안내 파일은 변경하지 않았다. 개인 경험은 서울거래·라덱셀의 키워드만 기재했다. 수치·성과·상환 경험을 만들지 않았다.

## 화면 대조

사용자의 마지막 요청인 plain 발표자료를 기준으로 확인했다. 이전 만화 스타일의 이미지 컨셉은 중단했고, 새 삽화나 이미지 컨셉을 승인받았다고 취급하지 않았다.

| 확인점 | 요구·기준 | 확인·수정 |
|---|---|---|
| 화면 톤 | 흰색 배경의 plain 발표자료 | 흰 슬라이드, 회색 바깥 배경, 남색 강조 한 색. 만화 이미지·질감·손글씨 없음 |
| 개인 경험 | 키워드만, 발표자가 설명 | 서울거래와 라덱셀 두 행. 불필요한 설명 문장 제거 |
| 제목·본문 | 큰 제목, 짧은 문장과 표 | 15장 분리, 긴 설명과 근거는 메모에 배치 |
| 과세 예시 | 금액과 연환산 비교율을 함께 표시 | 작은 PC 화면에서 표 높이 축소, 모바일에서 세 열을 모두 표시 |
| 모바일 | 세로로 읽고 넘기기 | 내용 길이에 따라 세로 스크롤. 하단 이동 버튼. footer까지 스크롤해 접근 가능 |
| 비교표 | 비교 조건을 가리지 않기 | 좁은 화면의 공제 비교표에 좌우 이동 안내 및 키보드 포커스 추가 |
| 이동 | 현재 장 링크·목차·키보드 | 직접 링크 시 브라우저 자동 스크롤을 유발하던 article ID 분리 |
| 인쇄 | 발표자료를 한 장씩 인쇄 | A4 가로 15장과 출처 부록 4장. 실제 PDF의 비교표·세액표를 렌더링해 확인 |

## 기능 확인

- Chromium에서 1440×900, 1366×768, 1280×720, 768×1024, 390×844, 360×800: 15장씩 총 90개 화면 상태 검사. 페이지 가로 넘침·본문/바닥글 겹침·PC 제어부 잘림 없음.
- 12개 기능 검사 통과: 처음/끝 경계·키보드, 목차·대화상자·포커스 복원, 전체화면 진입/종료, 직접 링크·뒤로 가기, 개인 경험 내용, Q&A 단일 답변 열기, 인쇄, 기존 안내 4개 경로, JS 비활성 대체 링크, 세액 계산, 양방향 터치·직후 탭, 세로 스크롤·모바일 표.
- 누진 세율 구간을 별도로 계산해 지방소득세를 더한 감소액 165·264·385만원 및 3년 단순 연환산 5.50·8.80·12.83%와 대조.
- 브라우저 오류 및 로컬 자원 응답 오류 없음. JS 문법 검사 통과.
- 브라우저 통합 도구는 초기화 시 파일 경로 오류로 사용할 수 없어 Playwright Chromium으로 확인했다. 물리적 휴대폰·Safari에서 검증한 것은 아니다.
- 임시 자동화 파일·스크린샷·검사용 PDF는 확인 후 삭제한다. 이 문서에 검증 범위와 결과를 남긴다.

## 내용 확인

- 조세특례제한법 제16조, 소득세법 제55조·제59조의3, 지방세법 제92조, 국세청 연금계좌 안내를 확인하고 해당 장의 출처에 연결.
- 엔젤투자지원센터 FAQ는 이전 확인 근거를 유지했다. 이번 재접속은 503으로 실패했다.
- 회사명·대표·업종은 사람인 공개 정보, 서비스 주제는 사용자 설명과 회사 홈페이지를 참조했다. 재무 수치는 기재하지 않았다.
- 악용 관련 보도는 2023-11-07 기사임을 표시하고 링크와 짧은 요약만 수록했다. 이번 회사에 대한 보도나 위법 판정으로 취급하지 않았다.
- 납입·서류 전달은 목표 일정이다. 이전 내부 발행결의 12/4와 참여 의사 마감 12/6의 불일치는 발표 메모에 남겼다. 노션을 수정하지 않았다.
- 세액 감소액의 연환산은 이자 지급·원금 보장·복리 수익률이 아님을 표시했다.


## 동일 금액 비교 보완 검증 · 2026-11-28

5~6장을 투자·저축 / 소비·기부 비교로 나누어 총 16장으로 변경했다. 기준은 총급여 1억원·추가 공제 전 과세표준 7,000만원, 추가 자금 1,000만원이다. 각 행은 독립된 선택이며 지방소득세를 포함한다.

| 방법 | 계산 근거 | 감소액 | 벤처투자와 차액 |
|---|---|---:|---:|
| 적격 벤처 직접투자 | 1,000 × 24% × 1.1 | 264만원 | 기준 |
| 연금저축 단독 | 공제 대상 600 × 12% × 1.1 | 79.2만원 | 184.8만원 |
| 연금저축+IRP | 공제 대상 900 × 12% × 1.1 | 118.8만원 | 145.2만원 |
| 일반 신용카드 | 추가 1,000 × 15% × 26.4% | 39.6만원 | 224.4만원 |
| 체크·현금영수증 | 공제 한도 250 × 26.4% | 66만원 | 198만원 |
| 일반기부금 | 적격 1,000 × 15% × 1.1 | 165만원 | 99만원 |
| ISA | 납입 공제 없음, 운용수익 과세특례는 별도 | 납입 시 0원 | 계산 제외 |

- 국세 누진세율 함수를 별도로 계산하고, 카드 최저사용액 공식을 반영해 화면의 감소액 5건과 차액 5건을 검증했다. 모든 값 일치.
- 연금 기존 한도 미사용, 카드 기존 일반 신용카드 사용액 2,500만원·자녀 한도 가산 없음·특별 사용분 없음, 일반기부금은 종교단체 외 적격 단체·기존/이월 기부금 없음·한도 내 금액을 가정했다. 다른 공제 변화 및 미래 인출세금·운용수익·손실은 제외했다.
- 소득세법 제59조의3·제59조의4, 조세특례제한법 제126조의2·제91조의18의 현행 기준을 확인하고 출처 연결.
- 비교 두 장을 1440×900, 1366×768, 1280×720, 768×1024, 390×844, 360×800에서 확인. 처음 한 장에 여섯 방법을 넣었을 때 생긴 높이 초과는 두 장으로 나누어 해결. 현재 12개 화면 모두 넘침·가림 없음.
- 흰 배경·남색 강조·큰 제목·세 열을 유지. PC와 모바일 비교표 화면, 인쇄 화면 두 장을 직접 열어 확인했다. 모바일 아래쪽 설명·근거 버튼까지 스크롤 가능.
- 전체 16장 순서·목차·마지막 버튼·발표 메모·출처·인쇄·오류 없음 확인. 기존 비교 장 외의 14개 슬라이드 내용은 직전 커밋과 일치한다.
- 확인은 Chromium의 화면 크기 모의검사이며 물리적 휴대폰 검사는 아니다. 임시 검사 이미지 파일은 확인 후 정리한다.


## 국내 현황·회사 사례·3년 수익·자금 흐름 보완 검증 · 2026-11-28

16장에서 20장으로 확장. 국내 현황, 서울거래 사례, 라덱셀 사례, 3년 수익 비교를 추가했다. 기존 자금 흐름을 다시 구성하고 소득 구간별 표의 연환산 방식을 새 비교표와 통일했다. 나머지 기존 14개 슬라이드의 데이터·문구는 직전 커밋과 일치한다. 기존 모임·지인용 만화 안내 파일은 수정하지 않았다.

### 자료와 해석

- 중소벤처기업부의 2026년 1~3분기 발표와 정부 게시본에서 연도별 투자액 및 전년 동기 대비 28.4%를 대조. 모든 막대는 각 연도 1~3분기이며 0에서 시작한다.
- 서울거래 공식 회사 소개·운영 규정·2023.12.04 CB 공지를 확인. 현재 모집, 일반 거래 서비스, 개인 경험을 섞지 않았다.
- 라덱셀 공식 연혁·개발 제품 및 회사 게시 조선비즈 기사(2026.08.24) 확인. 352억원 총사업비 / 정부지원금 279.5억원 / 7년 컨소시엄 과제를 민간 투자금으로 설명하지 않는다.
- ISA·연금계좌·연금 외 수령·이자 원천징수·지방소득세 특별징수 근거를 추가. 예금 14%×1.1, ISA 초과이익 9%×1.1, 일반 연금 외 수령 15%×1.1을 반영.

### 계산

독립된 기대값과 세금 경계 사례를 `node scripts/verify-briefing.mjs`로 검증했다. 5개 수익률×2개 연금 처리 방식, ISA 비과세 초과·손실, 연금 해지·과세제외 원금, 잘못된 입력, 연환산 일관성, 슬라이드·출처 참조를 확인했다.

| 방법 | 연 3% 가정의 공제+3년 증감액 | 비고 |
|---|---:|---|
| 이번 CB | 264만원 | 이자 0%, 전액 상환 가정 |
| 일반 예금 | 78.088782만원 | 매년 이자 과세 후 재예치 |
| 일반형 ISA | 92.727만원 | 3년 정상 해지, 200만원 이내 이익 |
| 연금저축 계좌 유지 | 171.927만원 | 인출세 전 |
| 연금저축+IRP 계좌 유지 | 211.527만원 | 인출세 전 |
| 연금저축 3년 후 해지 | 57.627045만원 | 일반 연금 외 수령세 반영 |
| 연금저축+IRP 3년 후 해지 | 47.727045만원 | 일반 연금 외 수령세 반영 |

연 7% ISA는 225.043만원 이익에서 2.479257만원 세금을 차감한다. 연금의 운용수익이 0%여도 3년 후 일반 해지에서는 초기 공제보다 해지세금이 커질 수 있음을 확인했다. 이는 특정 상품의 기대수익률 추정이나 투자 적합성 순위가 아니다.

기존 세액표의 단순 환산과 새 표의 복리 환산을 혼용하지 않도록 발표자료의 연환산을 5.22 / 8.12 / 11.47%로 통일했다. 환급 시점을 반영한 IRR은 아니다.

### 화면과 기능

- Chromium에서 1440×900, 1366×768, 1280×720, 768×1024, 390×844, 360×800의 전체 20장, 총 120개 상태에 페이지·본문 가로 넘침 및 본문/바닥글 겹침 없음.
- PC·휴대폰 크기의 비교표, 국내 현황, 두 회사 소개, 자금 흐름을 이미지로 확인. 모바일 자금 흐름은 처음의 아래쪽 화살표를 주체 사이로 이동해 방향을 읽기 쉽게 수정.
- 수익률 7%·-5% 및 연금 유지/해지 전환, CB·예금 값 고정, 화면 이동 후 선택값 유지, 선택창 키보드 조작 시 페이지 이동 방지, 메모·출처·목차 20장, 처음/끝, 뒤로 가기, 이름 기반 직접 링크와 기존 숫자 링크 확인.
- 인쇄 PDF 총 26쪽: 슬라이드 20쪽+출처·가정 6쪽. 첫 20쪽의 제목과 바닥글이 각각 해당 쪽에 존재함을 검사. 비교표·자금 흐름·세액표·라덱셀 장을 렌더링해 잘림 여부를 확인. 선택값과 계좌 유지/해지 설명도 인쇄에 표시.
- 검사 과정의 7% 연금 해지 예상 표시값을 잘못 적은 테스트 단언(158.1만원)은 독립 계산 158.210905만원에 맞춰 158.2만원으로 고침. 실제 화면 계산의 오류는 아니었다.
- 브라우저 실행 오류 없음. 물리적 휴대폰·Safari 검사는 수행하지 않음.
