# 지인·가족용 안내본 변경 내용

작성일: 2026-11-23.

새 안내 주소: [지인·가족용 만화](https://knhbae.github.io/batoners-cb-story/friends/)

## 대상별 구성

| 항목 | 모임 구성원용 | 지인·가족용 |
| --- | --- | --- |
| 제목 | 우리 모임의 다음 장 | CB 투자와 소득공제 · 지인·가족 안내 |
| 시작하는 이야기 | 모임 재원 고민과 구성원의 벤처투자 경험 | CB의 구조와 참여 조건 |
| 참여 대상 | 모임 구성원 | 모임 구성원의 지인·가족만 |

| 자금 흐름 예시 | 1,000만원 × 10명 = 1억원 | 같은 예시 사용. 실제 참여금액 조건과 구분 |
| 소득공제 예시 | 1,000만원 투자 기준 | 300만원 투자 기준 |

| 참여 의사 전달 | 구성원 참여 의사 확인 | 소개한 구성원에게 의사·금액 전달 후 회사 안내에 따라 계약·납입 |
| 제목·공유 미리보기 | 모임 구성원용 명칭 | 지인·가족용 명칭과 최소 금액을 표시 |
| 회사 정보 | 별도 링크 없음 | 2페이지와 전체 설명에서 사용자가 제공한 사람인 기업정보 링크 연결 |

3년 기준, 투자자 약정 이자 없음, 계약에 따른 중도 회수, 원금 손실 가능성, 12/6·12/18·1/15 목표 일정은 기존 구상을 이어받았습니다. 이 안내에서는 모집 상한액이나 총 참여인원을 새로 정하지 않았습니다. 10명은 설명용 예시입니다.

## 300만원 예시 계산

300만원 전액 공제, 동일 세율 구간, 종합소득금액의 50% 한도 충족, 다른 세액공제 변화 없음이라는 가정입니다.

| 투자공제 전 → 후 과세표준 | 지방소득세 포함 한계세율 | 단순 세액 감소액 | 3년 단순 연환산 |
| --- | --- | --- | --- |
| 3,000 → 2,700만원 | 16.5% | 49.5만원 | 5.50% |
| 7,000 → 6,700만원 | 26.4% | 79.2만원 | 8.80% |
| 1억 2,000 → 1억 1,700만원 | 38.5% | 115.5만원 | 12.83% |

계산식은 세액 감소액 ÷ 300만원 ÷ 3년 × 100입니다. 실제 지급 이자나 보장수익률을 뜻하지 않습니다. 근거: [조세특례제한법 제16조](https://www.law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1032239547), [국세청 종합소득세 세율](https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=7873&mi=2227), [지방세법 제92조](https://law.go.kr/LSW/lsLinkCommonInfo.do?lsJoLnkSeq=1029492599).

## 안내문 외 후속 확인

실제 발행결의서나 제3자 배정 사유가 투자자 전원의 자문 제공을 전제로 작성돼 있다면, 지인·가족에게도 그 전제를 적용할 수 있는지 확인하고 실제 배정 사유에 맞춰야 합니다. 이번 변경은 안내 사이트에 적용했습니다. 실제 발행서류의 현재 문구를 새로 대조한 결과는 아닙니다.

소개한 구성원에게 참여 의사를 먼저 전달하는 방식은 이번 안내본의 운영안입니다. 최종 연락 경로가 정해지면 마지막 장과 전체 설명의 해당 문구를 함께 수정합니다.

참여 대상 조건은 안내문에 명시합니다. 웹페이지는 공개 링크로 열리며, 로그인이나 참가 자격을 자동 확인하는 기능은 없습니다.

## 구현·검증

- `friends/`에 별도 만화와 전체 설명을 구성했습니다. 기존 안내의 본문·조건 파일은 수정하지 않았습니다.
- 삽화와 기본 스타일을 공유합니다. 지인·가족용 문구에 필요한 글꼴은 별도로 내보냈습니다.
- 외부 안내의 본문, 탭 제목, 공유 미리보기에 회사명을 노출하지 않습니다.
- PC·태블릿·모바일 5개 화면 크기에서 8장, 총 40개 상태를 검증했습니다.
- 3개 절세 예시, 앞뒤 이동, 목차, 전체 설명, 키보드·터치 스와이프·세로 스크롤, 직접 주소, 인쇄·JavaScript 비활성 대체 화면을 확인했습니다.
- 실물 기기 검증은 포함하지 않았습니다. 모바일 동작은 Chromium 터치 에뮬레이션입니다.
