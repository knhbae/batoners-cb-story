## 내용 확인

- 1,000만원은 자금 흐름 예시입니다. 구성원용 100만원부터, 지인·가족용 300만원부터 100만원 단위 조건을 유지했습니다.
- 공제 효과는 환급 증가 또는 납부 감소로 표현했습니다. 확정 환급액·입금일을 약속하지 않습니다.
- 원칙적인 3년 보유는 세제 혜택 유지 조건입니다. 3년 전에도 공제를 받을 수 있다는 설명을 함께 표시했습니다.
- 7페이지와 전체 설명에 같은 법령 취지를 적용했습니다. 실제 만기·중도 회수 권리는 계약으로 확인하도록 했습니다.
- 조세특례제한법 제16조 제2항의 현행 조문과 엔젤투자지원센터 FAQ 5·12·22번을 확인했습니다.
- 두 안내본의 기존 세액 예시와 진행 일정, 회사 정보 링크를 유지했습니다.

## 동작 확인

- 두 안내본 각각 8페이지 × 5개 화면 크기(총 80개 상태) 확인 통과.
- 페이지 넘김, 키보드, 목차, 직접 링크, 뒤로 가기, 계산 예시, 초점 복원, 터치 스와이프와 후속 탭, 세로 스크롤 확인 통과.
- 새 타임라인과 근거 이동을 두 안내본 × 5개 화면 크기에서 추가 확인했습니다. 가로 넘침과 첫 장 하단 문구 가림이 없었습니다.
- 전체 설명의 네 개 표, 자바스크립트 미사용 시 읽기 경로, 인쇄 스타일 확인 통과.
- 자바스크립트 구문 검사와 변경 파일 공백 검사 통과.
- 결과: `output/local/report.json`, `output/friends-local/report.json`, `output/investor-timeline/final/report.json`. 화면은 각 폴더에 보관합니다.

검증은 Chromium 브라우저와 모바일 화면·터치 모의 환경에서 진행했습니다. 실제 휴대폰 확인은 포함하지 않습니다. 내장 브라우저의 초기화 실패로 Playwright를 사용했습니다.
