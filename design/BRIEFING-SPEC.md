## 3년 수익 비교

- 기준: 1,000만원을 처음에 한 번 납입. 총급여 1억원, 추가 공제 전 과세표준 7,000만원, 충분한 세액과 미사용 공제 한도. 공제액 재투자·추가 납입 없음.
- 이번 CB: 이자 0%, 공제 효과 264만원, 미전환 원금 전액 상환 가정. 회사 신용위험·상환조건은 별도.
- 일반 예금: 연 3%가 3년간 같다고 가정. 매년 15.4% 이자 과세 후 원리금 재예치, 금융소득 종합과세 제외.
- ISA·연금: 수수료 차감 후·세전 연 수익률 -5 / 0 / 3 / 5 / 7% 선택. 예상·보장수익률이 아닌 시나리오.
- 일반형 ISA: 3년 정상 해지, 순이익 200만원 비과세·초과 양의 이익 9.9% 과세. 다른 손익통산·해외 원천세 제외.
- 연금저축 단독 공제 대상 600만원, IRP 합산 900만원. 초기 세액공제 79.2 / 118.8만원. 나머지 원금의 이후 연도 공제 전환은 제외.
- 연금 계좌 유지: 인출세 차감 전 계좌 가치로 계산. 즉시 쓸 수 있는 현금이 아님.
- 3년 후 일반 해지: 공제받지 않은 원금은 과세제외금액으로 확인, 나머지 양수 잔액에 16.5%. 정상 연금 수령·부득이한 사유·퇴직금 이전액은 제외.
- 합산효과 = 초기 공제액 + 운용·인출 후 증감액. 원금은 제외. 누적 비교율 = 합산효과 / 1,000만원. 연환산 = (1 + 누적 비교율)^(1/3) - 1. 환급 시점을 반영하는 IRR이 아님.
- 뒤쪽 소득 구간별 표도 같은 복리 환산을 사용. 기존 단순 환산 5.50 / 8.80 / 12.83% 대신 5.22 / 8.12 / 11.47%.
