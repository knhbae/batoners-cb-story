# 바토너스 CB 이야기 — 구현 기준

## 범위와 방향
- 8장 만화 리더. 공개 설명용 초안이며 신청·결제·개인정보 입력 기능 없음.
- 기존 설명의 사업 자문 목적, 자금 흐름, 조건부 소득공제, 3년 단순 연환산, 원금 위험, 일정 보존.
- 콘셉트: `concept-desktop.png`, 이미지 생성 도구로 생성. 사용자에게 별도 승인 요청 없이 제작하도록 위임받은 범위에서 선택.
- 원본 회사 서류·개인정보·내부 Notion 링크는 배포하지 않음.

## 디자인 토큰
- 바탕 #ede9df, 종이 #fffcf4, 잉크 #273a31, 녹색 #6d8060, 주황 #c57243.
- 좌측 손그림 만화 / 우측 읽기 영역의 펼친 책. 가운데 접힘과 얇은 종이 테두리.
- 제목·말풍선 Gaegu Bold, 본문 Pretendard 및 시스템 한글 폰트.
- 제목 40~70px, 본문 18~20px, 주석 14px. 모바일 제목 32~44px, 본문 16px 이상.
- 그림은 별도 생성한 자산. UI와 대사·표·날짜는 HTML 텍스트.
- 화살표는 일관된 stroke 2의 SVG. 페이지 인덱스는 클릭 가능한 8개 막대.

## 화면과 문구
1. 우리 모임의 다음 장 / CB 투자와 소득공제, 여덟 장의 만화로 알아봐요.
2. 함께 투자한다는 건 / CB 구조와 예금 보관 계획.
3. 돈은 이렇게 움직여요 / 1인 1,000만원 × 10명, 개인·회사·은행 흐름.
4. 세금은 얼마나 줄까요? / 3개 과세표준 예시 선택, 165·264·385만원.
5. 연 8.80%라는 숫자의 뜻 / 선택 예시에 따른 3년 단순 환산. 실제 이자 아님.
6. 이자는 자문회의에 / 회사 이자 수익과 사업 관련 자문, 비용·증빙.
7. 시작 전, 함께 확인해요 / 최소 금액, 기간, 무이자, 중도 회수와 원금 위험.
8. 다음 장은 이 일정으로 / 12/6, 12/18, 1/15 목표와 신고 안내.
- 상단 바토너스 / 목차 / 전체 내용, 하단 이전 / 8개 진행 막대 / 다음 이야기.
- 새로 필요한 상태: 목차 dialog, 원문·출처 dialog, 선택 예시. 책과 같은 색·서체 적용.

## 반응형·접근성
- 데스크톱 펼침, 760px 이하 그림/본문 세로 배치. 필요 시 세로 스크롤, 하단 넘김 도구 고정.
- 포인터 스와이프, 좌우 화살표 키, Home/End, 클릭, 페이지별 URL.
- native dialog와 focus 복원, 현재 페이지 알림, 스킵 링크, 명시적 이미지 alt.
- reduced-motion에서는 넘김 애니메이션 생략.

## 의도한 차이
- 콘셉트의 장식적인 불규칙 외곽선은 실제 HTML/CSS 종이 테두리로 간결하게 구현.
- 원본 그림에 포함된 한글 대신 재생성한 무문자 그림과 실제 HTML 대사 사용.
- 모바일은 두 쪽을 억지로 축소하지 않고 세로로 재배치.
- 세금 숫자는 정확한 계산 가정을 펼쳐 볼 수 있도록 자료 dialog에 연결.

## QA 인벤토리
- 8장 전진·후진, 처음/마지막, 연타, 키보드, 실제 touch swipe, 페이지 직접 URL, 뒤로가기.
- 목차 모든 항목, dialog 열기/닫기/Escape/포커스, 사례 3개 왕복, 표 숫자.
- 데스크톱 1440×1000, 1366×768, 모바일 390×844·360×800, 태블릿 768×1024.
- 각 페이지 그림 로드, 말풍선·본문 겹침, 잘림·수평 넘침, 작은 화면 표 스크롤.
- 전체 내용·외부 출처, 인쇄, reduce motion, HTTP 응답과 배포 파일 동일성.
- 비교 지점: 책 구성, 종이색/잉크, 제목/본문 크기, 그림 일관성, 말풍선, 하단 제어, 모바일 줄바꿈.
